# Community Events

The weekly Community Events calendar shown at https://blacklionret.com/events.
Presented by Black Lion Alliance.

- `calendar.html` · the published calendar (served to blacklionret.com/events)
- `data/events.json` · the event listings
- `tools/build_calendar.py` · builds calendar.html from the listings

Updated every Monday. Listings link to each host's own page; confirm details with the host.
